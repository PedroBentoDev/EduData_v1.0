Como funciona

Do dado à sua aplicação

Com o EduData, acessar informações educacionais é simples.

1

Escolha o endpoint

Encontre os recursos disponíveis na documentação e selecione os dados que deseja consultar.

2

Faça a requisição

Utilize uma requisição HTTP GET para consultar as informações disponibilizadas pela API.

3

Receba os dados

A API retorna os resultados em formato JSON, prontos para utilização em suas aplicações.
